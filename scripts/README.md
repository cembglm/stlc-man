# Operator scripts

- `external_integration_smoke.py`: exercises the external integration surface.
- `validate_generated.py`: validates generated Python tests against the configured robot capability contract before dispatch.
- `ifarlab_preflight.py`: separates ASRLab-local readiness failures from IFARLAB/human blockers.

Run scripts from the repository root so documented relative paths remain consistent.

IFARLAB setup and hand-off details are documented in `docs/IFARLAB_READINESS_RUNBOOK.md`.
